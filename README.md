# First Smile Dental Clinic Website

Static website for **First Smile Dental Clinic, Katihar**, led by **Dr. Chandan Kumar, BDS, MIDA, FAGE**. The site is built for local search visibility, fast loading, mobile-first browsing, and simple WhatsApp appointment booking.

## Pages

The final website contains only:

- Home
- About Us
- Services
- Contact

## Features

- Responsive dental clinic design using the existing First Smile color theme
- Official First Smile logo in the header, footer, favicon, Open Graph metadata, and schema image
- One-page service overview with treatment details and appointment buttons
- Professional contact page with clinic image, map, address, phone, email, hours, WhatsApp button, and contact form
- Click-to-call and WhatsApp appointment links
- Google Maps integration
- Smooth reveal animations
- `robots.txt` and `sitemap.xml`
- Canonical URLs, Open Graph tags, Twitter card metadata, and JSON-LD clinic schema

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Static hosting compatible

No framework or database is required.

## Local Preview

Start a local static server from this folder:

```bash
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## Deployment

Deploy this folder to any static hosting provider.
